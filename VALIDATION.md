# Проверка воспроизводимости

Дата: 8 ноября 2026 года. Python 3.11.15, macOS arm64, окружение `.venv`.

- До переноса реквизитов в `.env` все 39 непустых ячеек исходного анализа успешно
  выполнены по порядку в новом ядре за 55.3 с с настоящей учебной базой и CSV.
- После переноса реквизитов повторный полный запуск задержался на первой загрузке
  данных и был остановлен после более 5 минут. Полный запуск изменённого ноутбука
  не подтверждён; результаты ячеек очищены перед публикацией.
- Структура nbformat и синтаксис ячеек проверены; `pip check` прошёл.
- Реквизиты удалены из кода, текста задания и сохранённых результатов.
- Подключение читает локальный `.env` через python-dotenv и SQLAlchemy URL.create.
- Отдельный `SELECT 1` с параметрами из `.env` успешно выполнен после переноса реквизитов.
- `.env`, `.venv` и временные файлы исключены из Git.

Для запуска нужны интернет, доступ к учебной PostgreSQL и собственные действующие
реквизиты. Публичный CSV с курсом тенге загружается при выполнении ноутбука.
